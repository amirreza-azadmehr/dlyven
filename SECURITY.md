# Security

Supported: **1.x**.

If you find a security bug, **don’t open a public issue**. Use GitHub Security Advisories:

https://github.com/amirreza-azadmehr/dlyven/security/advisories/new

Say which version, which OS, and how to reproduce. We’ll try to get back within a week.

Nothing leaves your machine unless you download something. Don’t paste cookies or secrets into issues.
