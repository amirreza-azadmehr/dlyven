## Kurulum

1. [Son sürüme](https://github.com/amirreza-azadmehr/dlyven/releases/latest) gir.
2. **Tek** dosya indir:

| Bilgisayarın | Dosya |
| --- | --- |
| Windows | `Dlyven-windows-amd64.exe` |
| Mac (Intel veya Apple silicon) | `Dlyven-macos-universal.zip` |
| Linux x64 | `Dlyven-linux-amd64` |
| Linux ARM | `Dlyven-linux-arm64` |

3. Aç. Windows: `.exe`ye çift tık. Linux: önce `chmod +x Dlyven-linux-*` sonra çalıştır. Mac: zip’ten çıkar, `Dlyven.app` aç.
4. İlk açılışta internet lazım — yt-dlp ve ffmpeg’i kendi çekiyor. Sonra link yapıştır, indir.

Kurulum yok. Resmi sürümler Apple / Windows sertifikası olunca imzalanır. Kaynaktan mı? [geliştirici README](../../README.md).

## Nasıl kullanılır

1. Link yapıştır (ya da <kbd>Ctrl/⌘ V</kbd>, ya da URL / link dolu `.txt` bırak).
2. Bir saniye — başlık, kapak, bulduğu tüm kaliteler.
3. Video, ses, altyazı ya da kapak. Düşünmek istemezsen hazır ayarlar var.
4. Klasör seç, indir. Kuyrukta duraklat / devam / iptal.

Gizli gönderiler: Ayarlar → Giriş ve çerezler. Kısıtlı ağ: Ayarlar → Ağ.

## Siteler

YouTube, Instagram, TikTok, Spotify, X, Facebook, Vimeo, SoundCloud, Reddit, Twitch… ve [whatever else yt-dlp knows](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md). Tanımadığı linkler de iner; “Diğer site” yazar.

**YouTube** — linki yapıştır, video veya MP3, indir. Listelerde checklist var.

**Instagram** — reel veya gönderi URL’si. Gizli olanlar için giriş (çerez) lazım.

**TikTok** — yapıştır, video veya ses. Kısa link de olur.

**Spotify** — sesi Spotify’dan çekmiyoruz. Açık başlık/sanatçıyı okuyoruz, herkese açık bir kayıt buluyoruz, etiketliyoruz. Podcast yok.

## SSS

**Resmi YouTube / Instagram / TikTok uygulaması mı?** Hayır. Sadece yt-dlp üstüne masaüstü arayüz.

**Şarkıyı direkt Spotify’dan mı çekiyor?** Hayır. Sadece herkese açık bir kaydı eşliyor.

**Eve haber mi gidiyor?** Hayır.

**Dosyalarım nerede?** Windows `%AppData%\Dlyven` · Mac `~/Library/Application Support/Dlyven` · Linux `~/.config/Dlyven`.
