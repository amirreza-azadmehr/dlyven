## دامەزراندن

1. [دوایین وەشان](https://github.com/amirreza-azadmehr/dlyven/releases/latest) بکەرەوە.
2. **یەک** فایل دابگرە:

| کۆمپیوتەرەکەت | فایل |
| --- | --- |
| ویندۆز | `Dlyven-windows-amd64.exe` |
| ماک (ئەنتێل یان ئەپڵ سیلیکۆن) | `Dlyven-macos-universal.zip` |
| لینوکس x64 | `Dlyven-linux-amd64` |
| لینوکس ARM | `Dlyven-linux-arm64` |

3. بیکەرەوە. ویندۆز: دووجار کلیک لەسەر `.exe`. لینوکس: سەرەتا `chmod +x Dlyven-linux-*` پاشان جێبەجێی بکە. ماک: زیپ بکەرەوە و `Dlyven.app` بکەرەوە.
4. یەکەم جار ئینتەرنێتی دەوێت — خۆی yt-dlp و ffmpeg دەهێنێت. دوای ئەوە لینک بلکێنە و دایبگرە.

دامەزرێنەر نییە. بڵاوکراوە فەرمییەکان کاتێک بڕوانامەی ئەپڵ / ویندۆز هەبێت واژۆ دەکرێن. لە سەرچاوە؟ [READMEی گەشەپێدەر](../../README.md).

## چۆن بەکاری بهێنیت

1. لینک بلکێنە (یان <kbd>Ctrl/⌘ V</kbd>، یان URL / فایلی `.txt`ی پڕ لە لینک فڕێ بدە).
2. چرکەیەک — ناونیشان، وێنە، هەموو کوالێتییەکان.
3. ڤیدیۆ، دەنگ، ژێرنووس یان وێنە. ئەگەر حەوسەڵەت نییە، پێشوەختەکان بەکاربهێنە.
4. فۆڵدەر هەڵبژێرە، دایبگرە. لە ڕیزەکەدا وەستان / بەردەوام / هەڵوەشاندن.

پۆستی تایبەت: ڕێکخستنەکان → چوونەژوورەوە و کووکی. تۆڕی سنووردار: ڕێکخستنەکان → تۆڕ.

## ماڵپەڕەکان

یوتیوب، ئینستاگرام، تیک‌تۆک، سپۆتیفای، X، فەیسبووک، ڤیمۆ، ساوندکلاود، ڕێدیت، تویچ… و [whatever else yt-dlp knows](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md). لینکی نەناسراویش کار دەکات؛ دەنووسێت «ماڵپەڕی تر».

**یوتیوب** — لینک بلکێنە، ڤیدیۆ یان MP3، دایبگرە. لیستەکان چک‌لیستیان هەیە.

**ئینستاگرام** — لینکی ڕیل یان پۆست. تایبەتەکان پێویستیان بە چوونەژوورەوەیە (کووکی).

**تیک‌تۆک** — بلکێنە، ڤیدیۆ یان دەنگ. لینکی کورتیش باشە.

**سپۆتیفای** — دەنگ لە خودی سپۆتیفای ناکێشین. ناونیشان/هونەرمەندی گشتی دەخوێنینەوە، تۆمارێکی گشتی دەدۆزینەوە، تاگی دەکەین. پۆدکاست نییە.

## پرسیارە باوەکان

**ئەپی فەرمی یوتیوب / ئینستاگرام / تیک‌تۆکە؟** نەخێر. تەنها ڕووکارێکی دێسکتۆپە لەسەر yt-dlp.

**گۆرانی ڕاستەوخۆ لە سپۆتیفای؟** نەخێر. تەنها تۆمارێکی گشتی دەگونجێنین.

**ڕاپۆرت دەنێرێت؟** نەخێر.

**فایلەکانم لە کوێن؟** ویندۆز `%AppData%\Dlyven` · ماک `~/Library/Application Support/Dlyven` · لینوکس `~/.config/Dlyven`.
