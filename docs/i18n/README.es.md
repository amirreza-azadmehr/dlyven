## Instalar

1. Abre la [última versión](https://github.com/amirreza-azadmehr/dlyven/releases/latest).
2. Baja **un** archivo:

| Tu PC | Archivo |
| --- | --- |
| Windows | `Dlyven-windows-amd64.exe` |
| Mac (Intel o Apple silicon) | `Dlyven-macos-universal.zip` |
| Linux x64 | `Dlyven-linux-amd64` |
| Linux ARM | `Dlyven-linux-arm64` |

3. Ábrelo. Windows: doble clic al `.exe`. Linux: `chmod +x Dlyven-linux-*` y listo. Mac: descomprime y abre `Dlyven.app`.
4. La primera vez necesita internet — se baja yt-dlp y ffmpeg solito. Después pegas un enlace y ya.

Sin instalador. Las builds oficiales se firman cuando hay certificados de Apple / Windows. ¿Desde el código? [README de desarrollo](../../README.md).

## Cómo se usa

1. Pega un enlace (o <kbd>Ctrl/⌘ V</kbd>, o suelta una URL / un `.txt` de enlaces).
2. Un segundo — título, miniatura, todas las calidades que encuentre.
3. Vídeo, audio, subtítulos o miniatura. Hay presets si no quieres pensar.
4. Elige carpeta, descarga. Pausa / reanuda / cancela desde la cola.

Posts privados: Ajustes → Inicio de sesión y cookies. Red rara: Ajustes → Red.

## Sitios

YouTube, Instagram, TikTok, Spotify, X, Facebook, Vimeo, SoundCloud, Reddit, Twitch… y [whatever else yt-dlp knows](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md). Los enlaces raros también van; salen como “Otro sitio”.

**YouTube** — pega el enlace, vídeo o MP3, descarga. Las listas tienen checklist.

**Instagram** — URL del reel o post. Lo privado necesita que estés logueado (cookies).

**TikTok** — pégalo, vídeo o audio. Los links cortos valen.

**Spotify** — no sacamos el audio de Spotify. Leemos título/artista públicos, buscamos un match público y etiquetamos. No hay podcasts.

## FAQ

**¿App oficial de YouTube / Instagram / TikTok?** Ni de lejos. Solo una UI de escritorio sobre yt-dlp.

**¿Bajo canciones directo de Spotify?** No. Solo emparejamos una grabación pública.

**¿Manda telemetría?** No.

**¿Dónde está mi data?** Windows `%AppData%\Dlyven` · Mac `~/Library/Application Support/Dlyven` · Linux `~/.config/Dlyven`.
